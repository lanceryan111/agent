# Copilot 任务评估记录

每个任务记录一行，缺少数据写 unavailable，不猜测 token 或 credit 用量。

| 任务/类型 | 起始 SHA/证据 | 配置版本 | 完整模型名/模式/effort | 验收结果 | 人工纠正次数 | 总耗时 | AI credits | 后续缺陷/说明 |
|---|---|---|---|---|---|---|---|---|
| 待录入 | | | | | | | | |

任务组合至少包括：新增小功能、接口/配置变更、测试补充或重构、故障诊断、交付配置修改。使用相同输入与验收标准对比；模型比较时保持其他设置相同，配置比较时保持模型相同。

- 一次验收通过率 = 无人工纠正且验收通过的任务数 / 总任务数。
- 每个验收成功任务的 AI 成本 = 该组全部尝试的 credits（包括失败与重试）/ 验收成功任务数。成功数为零时记不可用，并保留失败总成本。
- 人工返工时间和后续缺陷单列；不要为了降低 credits 接受质量退化。
- 小样本只用于找方向；关键变化重复验证，记录波动。不得把平台共享额度下降全算到当前任务。
- 若没有每次任务的计费明细，用平台提供的可归因统计；无法归因则明确标记，不制造精确数字。
